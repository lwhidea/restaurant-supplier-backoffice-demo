# 餐饮供应商服务后台 Demo

此仓库保存交互原型及当前配套产品、技术文档。仓库设置为 GitHub Private。

## 内容

- `index.html`：项目队列交互优化版 demo（v2.22），可直接用浏览器打开。
- `PRD.md`：PRD 与线上开发计划（v2.28）。
- `TECHNICAL-PLAN.md`：技术方案（v2.28）。

## 运行

直接打开 `index.html` 即可预览。原型数据保存在浏览器 `localStorage`，仅用于演示；该 demo 未连接生产数据库或线上 API。

## 隐私

仓库仅限所有者及明确获授权的 GitHub 协作者访问。不要将仓库改为 Public，或在公开页面、公共静态托管服务中发布其中内容。
